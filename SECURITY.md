# Security policy

## Reporting a vulnerability

Do not publish exploit details or private user data in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected commit, Android version, device model, reproducible steps, and impact. Do not attach live malware samples or personal files.

## Scope

This repository is an early defensive scanning MVP. It is not yet a production antivirus product and must not be relied upon as the sole protection for a device.
